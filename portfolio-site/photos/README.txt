Tips:
  - Photos are cropped to fill the frame (centered), so keep the subject near the middle.
  - Use .jpg files under about 500 KB each so the page stays fast.
  - If a spot has no photo and you don't want it, delete that <figure class="photo-slot"> block in index.html.
  - Edit the alt="..." text on each <img> to describe your actual photo.
  - Check with Thermo Systems before posting photos from client sites.
